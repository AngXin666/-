# 溪盟商城自动化助手 v2.0.6

## 使用说明

### 1. 首次运行前准备

请确保：
- 已安装MuMu模拟器
- 模拟器分辨率设置为 540x960（竖屏）
- 已在模拟器中安装目标应用

### 2. 启动程序

双击 `溪盟商城自动化助手.exe` 启动程序

### 3. 首次启动

首次启动需要输入激活码，请联系管理员获取。

### 4. **重要：加载模型**

**首次使用或重启程序后，请先点击"🔄 加载模型"按钮**

- 程序会在主线程中加载所有AI模型
- 加载过程需要1-2分钟，请耐心等待
- 加载完成后按钮会变成"✓ 已加载"
- 只需加载一次，之后可以正常使用所有功能
- 如果不加载模型直接点击"开始运行"，会提示"模型正在后台加载中"

### 5. 配置账号文件

**重要：首次使用需要配置账号文件**

1. 打开 `data` 文件夹
2. 查看 `账号文件示例.txt` 了解账号文件格式
3. 在 `data` 文件夹中创建 `accounts.txt.enc` 文件
4. 按照示例格式填写账号信息：
   ```
   手机号----密码----归属人
   13800138000----password123----张三
   13900139000----password456----李四
   ```
5. 保存文件后，程序会自动加密账号文件

**注意**：
- 手机号、密码、归属人之间用 `----`（4个横线）分隔
- 每行一个账号
- 归属人可选，不填写则只需要：手机号----密码
- 文件编码必须是 UTF-8

### 6. 配置文件说明

- **config.yaml**: 主配置文件（模拟器路径等）
- **model_config.json**: 模型配置文件
- **transfer_config.json**: 转账配置文件
- **data/accounts.txt.enc**: 账号文件（加密）

首次运行时，程序会自动创建这些配置文件的示例，请根据实际情况修改。

### 7. GPU加速说明

✓ 程序已集成GPU加速支持！

- 如果你的电脑有NVIDIA显卡，程序会自动使用GPU加速
- 如果没有GPU或GPU不可用，程序会自动使用CPU模式
- 无需额外配置，程序会自动检测并选择最佳运行模式

GPU加速可以显著提升：
- 图像识别速度（OCR、YOLO检测）
- 页面检测速度
- 整体运行效率

### 8. 文件夹说明

- **data/**: 账号文件目录
- **models/**: 模型文件（请勿删除）
- **config/**: 配置文件
- **docs/**: 文档文件
- **login_cache/**: 登录缓存（自动生成）
- **screenshots/**: 截图文件（自动生成）
- **logs/**: 日志文件（自动生成）
- **reports/**: 报告文件（自动生成）
- **runtime_data/**: 运行时数据（自动生成）

### 9. 常见问题

**Q: 程序无法启动？**
A: 请检查是否有杀毒软件拦截，将程序添加到白名单

**Q: 找不到模拟器？**
A: 请在config.yaml中配置正确的模拟器路径

**Q: 模型加载失败？**
A: 请确保models文件夹完整，不要删除任何文件

**Q: 点击"开始运行"提示"模型正在后台加载中"？**
A: 请先点击"🔄 加载模型"按钮，等待模型加载完成后再运行

**Q: 账号总计为0？**
A: 
  1. 检查 data 文件夹中是否有 accounts.txt.enc 文件
  2. 查看 data/账号文件示例.txt 了解正确的账号文件格式
  3. 确保账号文件格式正确（手机号----密码----归属人）

**Q: GPU加速不工作？**
A: 
  1. 检查是否有NVIDIA显卡
  2. 确保显卡驱动是最新版本
  3. 程序会自动降级到CPU模式，不影响使用

**Q: 程序运行缓慢？**
A: 
  1. 如果有GPU，确保GPU加速已启用
  2. 关闭其他占用资源的程序
  3. 检查模拟器性能设置

5. 恢复配置文件和数据文件
